# Fidelity fund ranker

A Python command-line tool that ranks Fidelity funds by return and volatility. It uses Fidelity's public fund screener and Yahoo Finance price history unless you specify a smaller ticker set. It requires network access but no third-party Python packages.

Run from the repository root:

```bash
python Python/fidelity_fund_ranker/rank_fidelity_funds.py --help
```
