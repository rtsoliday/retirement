# Python programs

- [`retirement_simulator/`](retirement_simulator/): Tkinter retirement planning application, simulation engine, local configuration, mortality tables, and tests.
- [`mortgage_investment/`](mortgage_investment/): standalone Tkinter mortgage vs. investment calculator.
- [`fidelity_fund_ranker/`](fidelity_fund_ranker/): command-line fund ranking script.

Run the scripts with Python from any working directory using the paths in the repository [README](../README.md). The desktop applications require a graphical environment and Tkinter.
